## About ☕

This repository contains Java exercises, notes, and practical projects
created while studying the core concepts of Java programming through the Oracle Academy Java Fundamentals course.

The main objective is to build strong knowledge in:

- Core Java syntax and language fundamentals
- Java platform architecture (JVM, JDK and JRE)
- Standard Java project structure and organization
- Object-Oriented Programming (OOP) principles
- Software development best practices
- Clean, maintainable code following Java best practices

## Project Structure 📁

The exercises are organized following standard Maven and Java
project conventions. 

Each section contains its respective exercises and
implementations, simulating a real-world software project structure.

